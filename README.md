**Sunset Bay** — a top-down open-world crime game in vanilla JavaScript and Canvas 2D, no libraries and no assets: every car, rooftop, palm and siren is drawn and synthesised by the code itself. Explore a sun-soaked coastal city on foot or behind the wheel: steal any car (yank the driver out of a moving one, if you like), outrun a five-star wanted system with patrol cars and a police helicopter, and work through Rosa's fifteen-job story campaign — deliveries, checkpoint races, a stolen coupe, a street race against Kiko, rampages, escapes and one long sunset run. Earn cash, buy a pistol or an SMG at Lock & Load, lose the heat at Sunset Spray, heal at Burger Bay, and chase the day from dawn to neon night with three synthesised radio stations on the dial. Your money, weapons and campaign progress save between visits.

## Run it

```sh
node serve.ts   # then open http://localhost:8080 — or serve game/ with any static file server
```

To hand the entry in the way the bounty asks: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts` copies `game/` and `screenshots/` to the output directory and writes its `dossier.json`.
